Running CompuTech Website on Localhost:
For Windows:
1-
Install XAMPP:
Download and install XAMPP from https://www.apachefriends.org/index.html.
Launch XAMPP Control Panel and start Apache and MySQL services.
2-
Clone Repository:
Clone the 'computech' folder into the 'htdocs' directory of your XAMPP installation.
Usually located at C:\xampp\htdocs\.
3-
Database Setup:
Import the database included in the 'computech' folder into phpMyAdmin.
Open localhost/phpmyadmin/ in your browser, create a new database named 'computech', and import the provided SQL file.
4-
Launch Website:
Open your web browser and navigate to localhost/computech/ to view the website.

For Linux:
1-
Install LAMP Stack:
Install Apache, MySQL, and PHP on your Linux distribution.
For Ubuntu, you can use the following command: sudo apt-get install lamp-server^.
2-
Clone Repository:
Clone the 'computech' folder into the 'htdocs' directory of your Apache installation.
Usually located at /var/www/html/.
3-
Database Setup:
Import the database included in the 'computech' folder into phpMyAdmin.
Open localhost/phpmyadmin/ in your browser, create a new database named 'computech', and import the provided SQL file.
4-
Launch Website:
Open your web browser and navigate to localhost/computech/ to view the website.
